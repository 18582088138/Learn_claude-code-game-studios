## 基础能力

- [ ] 我能解释节点、场景、实例的关系。
- [ ] 我能找到玩家脚本并修改速度。
- [ ] 我能配置 Input Map。
- [ ] 我能解释物理更新与 delta 的用途，知道 move_and_slide 的速度约定。
- [ ] 我能说明一次信号从哪里发出、由谁处理。
- [ ] 我能设置碰撞层和掩码。
- [ ] 我会查看输出、报错位置和运行中的场景树。

## 可玩功能

- [ ] 玩家八方向移动，斜向速度合理。
- [ ] 摄像机跟随，玩家在画面中可见。
- [ ] 敌人按规则生成，数量可控。
- [ ] 敌人追击，接触伤害不会每帧无限触发。
- [ ] 自动攻击，目标消失和没有目标时行为合理。
- [ ] 子弹命中、超时后正确清理。
- [ ] 敌人死亡和掉落只结算一次。
- [ ] 经验拾取、升级阈值正常。
- [ ] 三选一升级暂停战斗，但 UI 仍可操作。
- [ ] 选择升级后属性确实变化。
- [ ] 玩家死亡与通关流程正常。
- [ ] 重开后清理敌人、子弹、经验与旧 UI，重置本局状态。
- [ ] 连续重开三次仍正常。
- [ ] 游戏内能完成开始、游玩、结算、重开。

## PC 与手机

- [ ] Windows 导出版本能脱离编辑器运行。
- [ ] 键盘和触屏共用移动接口。
- [ ] 已在真实目标手机运行，而非只模拟鼠标触摸。
- [ ] 摇杆与升级按钮多点触控不会串扰。
- [ ] 手机上的 HUD、文字、按钮可读可点。
- [ ] 不同宽高比下画面和 UI 合理。
- [ ] 切后台、返回、暂停行为合理。
- [ ] 记录了手机高敌人数量时的帧率与实际瓶颈。
- [ ] 玩完整局后没有持续增长的残留对象或明显性能下降。
